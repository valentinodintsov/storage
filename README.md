# Склад — микросервис учёта имущества

Учёт компьютерной техники, лицензий ПО, оргтехники и мебели с привязкой к контрагентам,
госконтрактам и государственным организациям. Имущество закрепляется за сотрудниками и выдаётся по
накладной (печатная форма по ОКУД 0504102) с электронной подписью.

Стек: Python 3.14, FastAPI, SQLAlchemy 2, Jinja2. Веб-интерфейс работает в любом современном браузере
(Windows, Linux, macOS, мобильные устройства) без внешних CDN — подходит для закрытых сетей.

## Быстрый старт

```bash
python3.14 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env        # заполните секреты
python -m app.seed          # демо-данные (необязательно)
uvicorn app.main:app --reload
```

Интерфейс: http://localhost:8000, REST API: http://localhost:8000/docs. Тесты: `pytest`.

Docker + PostgreSQL: `docker compose up --build` (строку подключения к `db` укажите в `.env`).

## Секреты

Все секреты лежат только в `.env` (в git не попадает), шаблон — `.env.example`.
Без них приложение не запустится: значений по умолчанию нет.

| Переменная | Назначение |
|---|---|
| `STORAGE_DATABASE_URL` | строка подключения к БД |
| `STORAGE_SECRET_KEY` | ключ JWT и HMAC простой ЭП (≥ 32 символов) |
| `STORAGE_ADMIN_PASSWORD` | пароль администратора, создаваемого при первом запуске |
| `POSTGRES_PASSWORD` | пароль PostgreSQL для docker-compose |

## Маршрут накладной

Черновик → подпись МОЛ → подпись руководителя (имущество закрепляется за получателем) →
подтверждение получения сотрудником. Подпись фиксирует SHA-256 содержимого документа, поэтому
изменение документа после подписания обнаруживается.

Провайдер ЭП (`STORAGE_SIGNATURE_PROVIDER`):
- `simple` — простая ЭП (повторный ввод пароля);
- `cades` — усиленная ЭП через КриптоПро ЭЦП Browser plug-in. Нужно положить `cadesplugin_api.js`
  в `app/static/vendor/`. Подпись проверяется на сервере утилитой `cryptcp` КриптоПро CSP
  (`STORAGE_CRYPTCP_PATH`): ГОСТ-подпись, цепочка до доверенного корневого УЦ и отзыв сертификатов
  (`STORAGE_CADES_CHECK_REVOCATION=false` — без проверки отзыва). Неверная подпись не принимается.
  Корневые сертификаты УЦ ставятся в доверенные у пользователя, от имени которого работает сервис.
  Без КриптоПро CSP на сервере (например, в Docker-образе) подпись помечается как непроверенная.
